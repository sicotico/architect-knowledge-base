## Respuesta


Azure Savings Plans cubre una amplia gama de recursos de Azure, aplicando descuentos automáticos a los más comunes utilizados en la nube. Estos son los principales recursos elegibles:

---

### **Recursos Cubiertos por Azure Savings Plans**

#### **1. Máquinas Virtuales (VMs)**
- Descuentos aplicables a las máquinas virtuales que se ejecutan en regiones específicas.
- Compatible con diferentes tamaños, series y familias de VM.

#### **2. Instancias de Contenedores**
- Ahorros en contenedores ejecutados bajo servicios como Azure Kubernetes Service (AKS).

#### **3. Servicios de Computación**
- Azure App Service: Aplicaciones web, móviles y de API.
- Funciones de Azure (Azure Functions) bajo el plan premium.

#### **4. Clústeres y Escalado Automático**
- Descuentos en recursos bajo escalado automático, dependiendo del compromiso horario.

#### **5. Recursos de Base de Datos**
- Servicios gestionados de base de datos como:
  - Azure SQL Database.
  - Azure Database for MySQL, PostgreSQL y MariaDB.

#### **6. Instancias Reservadas**
- Las instancias reservadas no están directamente incluidas en Savings Plans, pero estos planes se aplican a instancias que no tengan reservas.

---

### **Consideraciones Importantes**
1. **Flexibilidad**: Si cambias el tamaño, la región o la serie de tus máquinas virtuales o recursos, el ahorro se sigue aplicando mientras el recurso siga siendo elegible.
2. **Región**: Los planes son específicos de regiones, y los descuentos se aplican solo en las regiones cubiertas por el compromiso.
3. **Limitaciones**: No incluye servicios de almacenamiento ni redes (como Azure Blob Storage o Azure Virtual Network).

Si deseas optimizar tus costos, es fundamental revisar qué servicios usas y asegurarte de que sean elegibles para los descuentos. 😊

### **9. Preguntas Frecuentes**

#### **1. ¿Qué ocurre si supero mi compromiso horario?**
- Si tu uso supera el compromiso horario acordado, los recursos adicionales se facturarán al precio de pago por uso estándar.

#### **2. ¿Puedo cambiar o cancelar un plan?**
- Los Azure Savings Plans no pueden cancelarse una vez comprados. Sin embargo, puedes adquirir planes adicionales si cambian tus necesidades de consumo.

#### **3. ¿Qué sucede con los recursos no cubiertos por el plan?**
- Los recursos no cubiertos por el compromiso horario se cobrarán al precio de pago por uso estándar. Azure aplica automáticamente los descuentos del plan a los recursos elegibles para optimizar los ahorros.

#### **4. ¿Puedo combinar los Azure Savings Plans con otros descuentos?**
- Sí, Azure Savings Plans pueden combinarse con descuentos de Reservas de Capacidad o Beneficio Híbrido de Azure (AHB), permitiendo maximizar los ahorros.

#### **5. ¿Cómo evalúo si un Savings Plan es adecuado para mí?**
- Utiliza herramientas como el **Azure Pricing Calculator** y **Azure Cost Management** para analizar tus patrones de uso y determinar si tus cargas de trabajo son lo suficientemente estables como para beneficiarte de un compromiso a largo plazo.
