### Marco de Certificación de Azure ###

Vamos a ver el marco de certificación de Azure para que podamos entender a dónde se dirige esta certificación y dónde cae en la jerarquía general de certificaciones.

Microsoft tiene cuatro niveles de certificaciones. Está el nivel de Fundamentos, el nivel Asociado, el nivel Experto y el nivel Especialista.

El AZ-305 se encuentra en el nivel Experto. Y para llegar al nivel Experto, generalmente necesitas completar primero una certificación de nivel Asociado.

Entonces, lo que haces es que empiezas con el AZ-900, que es la certificación de Fundamentos.

Y luego puedes ir a cualquier certificación de nivel Asociado, como el AZ-104, que es la certificación de Administrador de Azure.

Después de eso, puedes tomar el AZ-305, que es la certificación de Arquitecto de Soluciones de Azure.

Esto te da una idea de cómo Microsoft estructura sus certificaciones.

Cada uno de estos niveles se basa en el conocimiento del nivel anterior, y el nivel Experto realmente espera que tengas un conocimiento profundo y práctico de los conceptos de Azure.

### Plan de Estudios ###

El plan de estudios para el AZ-305 se divide en cuatro dominios principales:

1. Diseño de Soluciones de Monitoreo
2. Diseño de Soluciones de Identidad y Seguridad
3. Diseño de Soluciones de Almacenamiento de Datos
4. Diseño de Soluciones de Continuidad de Negocio

Vamos a desglosar cada uno de estos dominios y ver qué temas específicos se cubren en el examen.

#### Diseño de Soluciones de Monitoreo ####

En este dominio, necesitas entender cómo diseñar soluciones de monitoreo en Azure.

Esto incluye el uso de Azure Monitor, Log Analytics y Application Insights para monitorear la salud y el rendimiento de tus aplicaciones y servicios.

También necesitas saber cómo configurar alertas y diagnósticos para identificar y resolver problemas rápidamente.

#### Diseño de Soluciones de Identidad y Seguridad ####

Este dominio cubre cómo diseñar soluciones de identidad y seguridad en Azure.

Necesitas entender cómo usar Azure Active Directory (Azure AD) para gestionar identidades y accesos.

También necesitas saber cómo implementar políticas de seguridad y cumplimiento, y cómo usar herramientas como Azure Security Center y Azure Sentinel para proteger tus recursos en la nube.

#### Diseño de Soluciones de Almacenamiento de Datos ####

En este dominio, necesitas saber cómo diseñar soluciones de almacenamiento de datos en Azure.

Esto incluye el uso de Azure SQL Database, Azure Cosmos DB, y Azure Blob Storage para almacenar y gestionar datos.

También necesitas entender cómo diseñar soluciones de alta disponibilidad y recuperación ante desastres para tus bases de datos y almacenes de datos.

#### Diseño de Soluciones de Continuidad de Negocio ####

Este dominio cubre cómo diseñar soluciones de continuidad de negocio en Azure.

Necesitas entender cómo implementar soluciones de respaldo y recuperación para proteger tus datos y aplicaciones.

También necesitas saber cómo diseñar soluciones de alta disponibilidad y recuperación ante desastres para garantizar la continuidad de tus operaciones empresariales en caso de una interrupción.
