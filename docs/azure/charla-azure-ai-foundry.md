# Charla Azure AI Foundry


> **Pregunta original:**
> 
Refina este promt para usarse con ChatGPT Deep research:
Soy un arquitecto cloud, con experiencia en RPA , AWS y con especialidad en infraestructura o servicios core de Azure. Quiero dar una charla sobre Azure AI Foundry, antiguamente Azure AI Studio. Necesito que estructures dos documentos, un guión y una ppt , con el contenido para la charla. Esta se debe de centrar en un ejemplo de desarrollo en Azure AI Foundry , exportarlo y ejecutarlo en un App Service. Quiero enseñar lo fácil que es generar un MVP o una aplicación para un caso reducido.

**Prompt Refinado:**

Soy arquitecto cloud con experiencia en automatización RPA, AWS, y especializado en infraestructura y servicios core de Azure. Estoy preparando una charla técnica enfocada en **Azure AI Foundry** (previamente conocido como Azure AI Studio). Mi objetivo es demostrar, mediante un ejemplo práctico y reducido, cómo desarrollar una solución utilizando Azure AI Foundry, exportar el proyecto generado y desplegarlo fácilmente en Azure App Service, destacando especialmente la sencillez y rapidez para crear un MVP (Producto Mínimo Viable).

Por favor, genera dos documentos estructurados:

1. **Guión detallado** para guiarme durante la charla:
   - Introducción breve a Azure AI Foundry y su cambio reciente desde Azure AI Studio.
   - Caso práctico sencillo y concreto (propón un ejemplo adecuado).
   - Pasos claros, secuenciados y fáciles de seguir para:
     - Desarrollar la aplicación en Azure AI Foundry.
     - Exportar el proyecto.
     - Implementar el proyecto en Azure App Service.
   - Recomendaciones prácticas o tips para una implementación exitosa.
   - Conclusión enfatizando la facilidad para generar rápidamente un MVP.

2. **Presentación PPT** con estructura sugerida y contenido clave:
   - Diapositiva introductoria con contexto breve y objetivos.
   - Resumen visual del caso práctico elegido.
   - Proceso ilustrado del desarrollo en Azure AI Foundry (capturas sugeridas, diagramas conceptuales).
   - Pasos visuales para exportación e implementación en Azure App Service.
   - Beneficios y valor diferencial al usar Azure AI Foundry para MVPs.
   - Diapositiva de conclusiones y recomendaciones.

La estructura debe ser didáctica, práctica y orientada a demostrar claramente la facilidad y agilidad en crear aplicaciones con Azure AI Foundry integradas a Azure App Service.
