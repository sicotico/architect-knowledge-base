### 🔷 Componentes principales del diagrama:

#### 1. **Frontend (Usuario)**
- Aplicación web / móvil
- Azure Static Web Apps o Azure App Service

#### 2. **API / Backend**
- Azure Functions o Azure App Service (API RESTful)
- Comunicación segura con los servicios de IA y datos

#### 3. **Servicios de IA**
- Azure OpenAI Service (GPT, Codex, etc.)
- Azure Cognitive Services (Vision, Language, Speech, etc.)
- Azure Machine Learning (modelos personalizados)

#### 4. **Datos**
- Azure Blob Storage (datos no estructurados: imágenes, audio)
- Azure SQL Database / Cosmos DB (datos estructurados)
- Azure Data Lake (almacenamiento de big data)
- Azure Synapse / Data Factory (ETL y analítica)

#### 5. **Orquestación y Automatización**
- Azure Logic Apps / Azure Data Factory
- Azure ML Pipelines (entrenamiento/implementación)

#### 6. **Seguridad y Control de Acceso**
- Azure Active Directory (Autenticación)
- Azure Key Vault (gestión de secretos y claves)
- Azure API Management (control y monetización de APIs)

#### 7. **Monitorización y DevOps**
- Azure Monitor / Application Insights
- GitHub Actions / Azure DevOps (CI/CD)
