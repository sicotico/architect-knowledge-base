# Homólogos Azure AWS


> **Pregunta original:**
> 
Cual es el homologo del servicio de Azur ePolicy y blueprints en AWS ?

---


## Respuesta


El equivalente en AWS de **Azure Policy** es una combinación de **AWS Config Rules** y **Service Control Policies (SCPs)** dentro de **AWS Organizations**. Estas herramientas permiten establecer y aplicar políticas para asegurar que los recursos de AWS cumplen con las normas y requisitos de tu organización.

Por otro lado, el equivalente de **Azure Blueprints** en AWS es **AWS CloudFormation** y **AWS Service Catalog**. **AWS CloudFormation** te permite modelar y aprovisionar recursos de AWS de forma automatizada y repetible, mientras que **AWS Service Catalog** te ayuda a crear y gestionar catálogos de servicios de TI aprobados para su uso en AWS.

Resumiendo:

- **Azure Policy** ⇒ **AWS Config Rules** y **Service Control Policies (SCPs)**
- **Azure Blueprints** ⇒ **AWS CloudFormation** y **AWS Service Catalog**
