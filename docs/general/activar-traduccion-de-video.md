Para activar la función de traducción de videos en Microsoft Edge, sigue estos pasos:

1. **Cerrar Microsoft Edge**: Antes de realizar cualquier cambio, asegúrate de que Microsoft Edge esté cerrado.

2. **Modificar el acceso directo**:
   - Haz clic derecho en el acceso directo de Microsoft Edge y selecciona "Propiedades".
   - En la pestaña "Acceso directo", busca el campo llamado "Destino".
   - Después de `msedge.exe`, agrega el siguiente modificador: `--enable-features=msVideoTranslateOverlayButton`. Esto permitirá activar la función experimental de traducción de video.
   - Haz clic en "Aplicar" y luego en "Aceptar".

3. **Iniciar Microsoft Edge**: Abre Edge usando el acceso directo modificado.

4. **Habilitar la traducción de videos**:
   - Ve a **Configuración > Idiomas** en el menú de Edge.
   - Busca la opción "Ofrecer traducir videos en sitios compatibles" y actívala.
   - Navega a YouTube (o cualquier otro sitio compatible), reproduce un video, y verás un botón nuevo para traducir el video. Puedes elegir el idioma de origen y el idioma al que deseas traducir.

5. **Descarga del modelo de idioma**: La primera vez que uses esta función, Edge descargará el modelo de traducción necesario para el idioma seleccionado. Este proceso es único para cada idioma.
