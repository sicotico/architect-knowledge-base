# Atajo comentar bloque Colab


> **Pregunta original:**
> 
En Colab ,¿cual es el atajo de teclado para comentar un bloque de lineas de código?

---


## Respuesta


En Google Colab, el atajo de teclado para **comentar o descomentar** un bloque de líneas de código seleccionado es:

**Ctrl + /**  (en Windows y Linux)  
**Cmd + /**  (en Mac)

Este atajo funciona tanto para una sola línea como para varias líneas seleccionadas: coloca un `#` al inicio de cada línea o lo elimina si ya está comentado.
