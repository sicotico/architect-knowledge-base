# Editores WYSIWYG para Windows


> **Pregunta original:**
> 
Editor web instalable lo que ves es lo que hay para window 

---


## Respuesta


Parece que estás buscando un editor de texto "WYSIWYG" (Lo Que Ves Es Lo Que Hay, por sus siglas en inglés) que se pueda instalar localmente en Windows. Aquí te proporciono algunas de las mejores opciones que cumplen con estos requisitos:

### 1. **TinyMCE**
- **Descripción**: TinyMCE es uno de los editores WYSIWYG más conocidos. Aunque originalmente está diseñado para integrarse en aplicaciones web, también tiene una versión de escritorio.
- **Características**: Es altamente personalizable y tiene plugins para casi cualquier funcionalidad. Además, su interfaz es muy amigable y similar a la de Microsoft Word.
- **Enlace**: [https://www.tiny.cloud/](https://www.tiny.cloud/)

### 2. **CKEditor**
- **Descripción**: CKEditor es otro editor WYSIWYG muy popular. Dispone de una versión autoalojada que puedes instalar en Windows.
- **Características**: Tiene una interfaz moderna y características avanzadas, como edición colaborativa, inserción multimedia, y soporte para edición de HTML.
- **Enlace**: [https://ckeditor.com/](https://ckeditor.com/)

### 3. **BlueGriffon**
- **Descripción**: BlueGriffon es un editor web WYSIWYG instalado localmente, basado en Gecko (el motor de Firefox). Es muy útil para editar HTML y CSS.
- **Características**: Incluye soporte para HTML5 y CSS3, una amplia gama de herramientas, y una interfaz bastante intuitiva.
- **Enlace**: [http://bluegriffon.org/](http://bluegriffon.org/)

### 4. **KompoZer**
- **Descripción**: KompoZer es un editor web WYSIWYG gratuito y de código abierto, diseñado para ser fácil de usar y con una funcionalidad "lo que ves es lo que hay". Aunque ya no se actualiza tanto, sigue siendo una opción sencilla para la creación de páginas web.
- **Características**: Editor de HTML con una interfaz muy simple y es adecuado para principiantes.
- **Enlace**: [http://kompozer.net/](http://kompozer.net/)

### 5. **Brackets (con extensiones WYSIWYG)**
- **Descripción**: Brackets es un editor de código para diseñadores web que también puede utilizarse como editor visual con las extensiones correctas.
- **Características**: Permite la edición en tiempo real y tiene un buen conjunto de extensiones que agregan funciones WYSIWYG, lo cual hace que puedas ver los resultados al instante.
- **Enlace**: [http://brackets.io/](http://brackets.io/)

### 6. **Silex (Editor de Sitios Web)**
- **Descripción**: Silex es un editor gratuito y de código abierto que funciona como un constructor de sitios web basado en el navegador, pero también se puede ejecutar localmente en tu computadora.
- **Características**: Ofrece un editor visual en el que puedes arrastrar y soltar elementos. Es ideal para crear sitios web sin necesidad de escribir código.
- **Enlace**: [https://www.silex.me/](https://www.silex.me/)

### 7. **Adobe Dreamweaver**
- **Descripción**: Aunque es una solución más profesional y de pago, Dreamweaver es un editor WYSIWYG que permite editar sitios web de manera visual y también a través del código.
- **Características**: Es muy versátil y tiene una interfaz muy intuitiva, además de soporte para HTML, CSS, y JavaScript. Es útil tanto para diseñadores principiantes como avanzados.
- **Enlace**: [https://www.adobe.com/products/dreamweaver.html](https://www.adobe.com/products/dreamweaver.html)

### Resumen
- Si buscas una opción gratuita y simple, **BlueGriffon** o **KompoZer** son buenas opciones.
- Para una opción profesional y avanzada, **Adobe Dreamweaver** es la opción ideal.
- **CKEditor** y **TinyMCE** son más avanzados y funcionan tanto localmente como en un entorno web.
  
Espero que esta lista te sea útil para encontrar un editor web WYSIWYG instalable que se adapte a tus necesidades. ¡Si necesitas más detalles o alguna recomendación específica, no dudes en preguntar!
