# Extracción de texto PDF


> **Pregunta original:**
> 
Como vas ?
> En el PDF hay preguntas y respuestas. mezcladas con imágenes tanto en preguntas como en respuestas. Necesito reconocer los textos de las preguntas y respuestas y si tiene imágenes extraerlas para formar un documento de pages

---


## Respuesta


Para extraer preguntas, respuestas e imágenes del PDF y crear un documento en Pages, te propongo el siguiente flujo de trabajo:

1. **Extracción de preguntas y respuestas**:
   - Cada pregunta está generalmente numerada y tiene varias opciones de respuesta.
   - Las respuestas correctas están indicadas inmediatamente después de cada conjunto de opciones.
   
   Ejemplo de formato:
   
   **Pregunta #1:**
   *Describe la solución para verificar si los desarrolladores de Fabrikam aún requieren permisos para la Aplicación1 en Azure AD.*
   A. Crear una revisión de acceso en Azure AD.  
   B. Crear un runbook de Azure Automation con el cmdlet Get-AzRoleAssignment.  
   **Respuesta correcta**: A
   
2. **Extracción de imágenes**:
   - Algunas imágenes pueden estar presentes como parte de las preguntas o respuestas.
   - Identificarlas es sencillo si podemos usar OCR o visualmente detectarlas.

3. **Conversión a Pages**:
   - Las preguntas y respuestas se formatearán en Pages como texto.
   - Las imágenes serán insertadas en las preguntas o respuestas que las contengan.
