Un fichero `urls.txt` para usar con **Synology Download Station** debe contener una lista de URLs, una por línea, indicando los enlaces que deseas descargar. Este archivo es compatible con descargas HTTP, HTTPS, FTP, y torrents.

### Ejemplo de un archivo `urls.txt`:

```txt
https://example.com/archivo1.zip
https://example.com/archivo2.pdf
ftp://ftp.example.com/recurso3.tar.gz
magnet:?xt=urn:btih:abcdef1234567890abcdef1234567890abcdef12&dn=nombre_del_torrent
http://example.com/videos/video4.mp4
```

### Instrucciones para usarlo:
1. Crea un archivo de texto con un editor como **Notepad** (Windows), **TextEdit** (Mac, en formato de texto plano), o cualquier editor de texto en Linux.
2. Guarda el archivo con el nombre `urls.txt`.
3. Abre **Synology Download Station**.
4. Ve a la opción para agregar descargas.
5. Importa el archivo `urls.txt` o copia y pega el contenido en la sección correspondiente.

¡Listo! Synology Download Station comenzará a descargar cada enlace de la lista.
