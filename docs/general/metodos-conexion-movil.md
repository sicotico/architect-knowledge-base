# Métodos conexión móvil


> **Pregunta original:**
> 
¿Qué dos métodos se utilizan para conectar directamente dispositivos móviles, como tablets y smartphones, a una red de datos? 
Wimax
comunicacion de dato smoviles
bluetooth
ethernet
wifi
> ¿Cuál es la representación válida más corta de la dirección IPv6 2001:0DB8:0000:1470:0000:0000:0000:0200?

---


## Respuesta


Los **dos métodos más comunes para conectar directamente dispositivos móviles como tablets y smartphones a una red de datos** son:

✅ **Wi-Fi**  
✅ **Bluetooth**

### Explicación:
- **Wi-Fi**: Permite que los dispositivos móviles se conecten de forma inalámbrica a una red de datos, generalmente a través de un router o punto de acceso.
- **Bluetooth**: Aunque su principal uso es para la conexión entre dispositivos (como auriculares, teclados, etc.), también puede usarse para compartir conexión a internet mediante funciones como "tethering" o compartir datos móviles.

---

### Opciones incorrectas:
- **WiMAX**: Es una tecnología de acceso inalámbrico de largo alcance, pero no es común en dispositivos móviles actuales.
- **Ethernet**: Requiere cableado físico, y los móviles normalmente no tienen puertos Ethernet.
- **Comunicación de datos móviles**: No es un método de conexión directa entre dispositivos, sino el uso de redes celulares (3G/4G/5G), lo cual no responde directamente a la pregunta.

La **representación válida más corta** de la dirección IPv6:

**`2001:0DB8:0000:1470:0000:0000:0000:0200`**

es:

### ✅ `2001:DB8:0:1470::200`

---

### ¿Cómo se acorta?

1. **Eliminar ceros a la izquierda** en cada bloque hexadecimal:  
   - `0DB8` → `DB8`  
   - `0000` → `0`  
   - `0200` → `200`  
   Entonces queda: `2001:DB8:0:1470:0:0:0:200`

2. **Reemplazar la secuencia más larga de ceros consecutivos con `::`** (solo una vez en la dirección):  
   - `0:0:0` → `::`

   Resultado final: `2001:DB8:0:1470::200`
