# Text Extraction in macOS


> **Pregunta original:**
> 
quiero la funcionalidad de text extractor en MacOS?


---


## Respuesta


Para extraer texto en **macOS**, existen varias maneras de hacerlo. A continuación te menciono algunas opciones, desde las más simples con las herramientas integradas hasta el uso de aplicaciones de terceros que ofrecen funcionalidades avanzadas.

### Métodos integrados en macOS:

#### 1. **Captura de pantalla con OCR (Reconocimiento Óptico de Caracteres) usando "Vista Previa"**:
   macOS no incluye de manera predeterminada un extractor de texto desde imágenes, pero puedes hacerlo utilizando herramientas de terceros combinadas con la captura de pantalla. Aquí te explico una opción simple:
   - Haz una **captura de pantalla** de la parte que contiene el texto (Cmd + Shift + 4).
   - Abre la captura en **Vista Previa**.
   - A continuación, utiliza una app de OCR para extraer el texto (puedes usar la herramienta "Live Text" si tu Mac es compatible).

#### 2. **Live Text** (Disponible en macOS Monterey en adelante):
   - Si tienes un Mac compatible con macOS Monterey o posterior, puedes usar **Live Text** para extraer texto de imágenes directamente.
   - Solo debes abrir la imagen en **Vista Previa** o cualquier otra app compatible (como Safari, Fotos, etc.).
   - Si el texto es reconocible, el cursor cambiará cuando pases sobre el texto y podrás seleccionarlo, copiarlo y pegarlo en otro lugar.

### Aplicaciones de terceros para extraer texto (OCR):

Si necesitas extraer texto de documentos de manera más frecuente o avanzada, existen aplicaciones de terceros que ofrecen funciones OCR (Reconocimiento Óptico de Caracteres). Algunas opciones recomendadas son:

#### 1. **PDFPen**:
   Es una aplicación popular en macOS que permite editar PDFs y extraer texto de imágenes con OCR integrado.

#### 2. **Prizmo**:
   Prizmo es una de las aplicaciones más completas de OCR para macOS, que permite escanear documentos, reconocer texto en imágenes y exportarlo en varios formatos.

#### 3. **OneNote**:
   OneNote, de Microsoft, también tiene una funcionalidad OCR incorporada. Puedes pegar una imagen en una nota y, haciendo clic derecho sobre ella, seleccionar **Copiar texto de la imagen**.

#### 4. **TextSniper**:
   Es una aplicación ligera y fácil de usar que permite extraer texto de cualquier cosa en la pantalla usando un atajo de teclado. Es muy útil para extraer texto de videos, imágenes, PDFs, etc.

#### 5. **Google Keep**:
   Google Keep también tiene una funcionalidad OCR sencilla. Puedes subir una imagen a una nota en Google Keep, y luego utilizar la opción "extraer texto de la imagen".

### Proceso paso a paso con TextSniper:
1. Descarga **TextSniper** desde su sitio web.
2. Instálalo y configúralo.
3. Cuando quieras extraer texto de la pantalla, selecciona el área del texto usando el atajo de teclado (generalmente Cmd + Shift + 2).
4. TextSniper automáticamente copiará el texto al portapapeles.

Cada una de estas opciones tiene distintas ventajas según tus necesidades. Si tu Mac es compatible con **Live Text**, probablemente esta sea la opción más simple, pero si necesitas extraer texto de fuentes más diversas, aplicaciones como **TextSniper** o **Prizmo** son excelentes herramientas.
