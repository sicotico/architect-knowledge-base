#### Diseñar soluciones de autenticación y autorización

**Azure Active Directory (Azure AD)**

Azure AD es un servicio de gestión de identidad y acceso basado en la nube que ayuda a tus empleados a iniciar sesión y acceder a recursos:

- **Internos**: Aplicaciones dentro de la red corporativa.
- **Externos**: Aplicaciones en la nube como Microsoft 365, el portal de Azure y miles de otras aplicaciones SaaS.

**Autenticación Multi-Factor (MFA)**
MFA es un proceso donde un usuario es solicitado a presentar dos o más piezas de evidencia (o factores) para una autenticación exitosa:

- Algo que el usuario sabe (contraseña).
- Algo que el usuario tiene (un dispositivo de autenticación, como un teléfono).
- Algo que el usuario es (huella digital).

**Beneficios de Azure AD**
- **Seguridad Mejorada**: Protección contra el acceso no autorizado.
- **Acceso Condicional**: Políticas que aplican controles específicos a solicitudes de acceso.
- **Autenticación sin contraseña**: Métodos como Windows Hello for Business, llaves de seguridad FIDO2 y la aplicación Microsoft Authenticator.

**Fuente: Documentación de Microsoft**

**Alta Disponibilidad y Recuperación ante Desastres (HA/DR)**
- La alta disponibilidad se refiere a la capacidad del sistema para funcionar continuamente sin fallos durante un periodo de tiempo.
- La recuperación ante desastres se refiere a las estrategias y procesos implementados para restaurar las operaciones tras un evento catastrófico.

**Azure Site Recovery**
- Permite la replicación de máquinas virtuales y aplicaciones a una región secundaria de Azure.
- **Beneficios**: Minimiza el tiempo de inactividad y la pérdida de datos durante eventos imprevistos.

**Azure Backup**
- Servicio que proporciona copias de seguridad automatizadas y recuperación de datos.
- **Características**: Retención a largo plazo, cifrado y restauración de datos a nivel granular.

### Asegurar grupos de Microsoft Entra

#### Tipos de Grupos en Microsoft Entra

**Grupos de Seguridad**: Usados para administrar el acceso a recursos en Azure AD.

**Grupos de Microsoft 365**: Usados para la colaboración entre usuarios, como compartir archivos y correos electrónicos.

#### Crear y Gestionar Grupos de Seguridad

**Pasos para crear un grupo de seguridad**:

1. Inicia sesión en el portal de Azure.
2. Navega a Azure Active Directory > Grupos > Nuevo grupo.
3. Selecciona "Grupo de Seguridad".
4. Proporciona un nombre y una descripción para el grupo.
5. Añade miembros al grupo.
6. Haz clic en "Crear".

#### Políticas de Grupo

Las políticas de grupo en Microsoft Entra ayudan a asegurar que los grupos se gestionen de manera consistente y segura. Ejemplos de políticas incluyen:

- **Revisión de miembros**: Asegura que los miembros de los grupos se revisen periódicamente.
- **Asignaciones dinámicas**: Automatiza la gestión de miembros del grupo basándose en reglas definidas.

**Fuente: Documentación de Microsoft**

### Acceso a Aplicaciones de Microsoft Entra

#### Registro de Aplicaciones en Microsoft Entra

Registrar una aplicación en Microsoft Entra permite que la aplicación interactúe con los recursos de Azure y otros servicios de Microsoft. 

**Pasos para registrar una aplicación**:

1. Inicia sesión en el portal de Azure.
2. Navega a Azure Active Directory > Registros de aplicaciones > Nuevo registro.
3. Proporciona un nombre para la aplicación.
4. Selecciona el tipo de cuenta soportado.
5. Proporciona una URL de redirección si es necesario.
6. Haz clic en "Registrar".

#### Autorización y Permisos

Las aplicaciones registradas necesitan permisos para acceder a recursos. Puedes configurar permisos API y delegados para la aplicación en la sección de "Permisos API" de su registro.

#### Configuración de Certificados y Secretos

Para asegurar la comunicación entre la aplicación y Azure, puedes configurar certificados y secretos. Estos se pueden encontrar en la sección "Certificados y secretos" del registro de la aplicación.

### Diseñar gobernanza

#### Azure RBAC

**Control de Acceso Basado en Roles (RBAC)**: Permite la gestión de quién tiene acceso a los recursos de Azure, qué pueden hacer con esos recursos y a qué áreas tienen acceso.

**Principales Componentes de Azure RBAC**:

- **Roles**: Colección de permisos. Ejemplos incluyen "Lector", "Colaborador" y "Propietario".
- **Asignaciones de Roles**: Proceso de otorgar roles a usuarios, grupos o principales de servicio.
- **Ámbitos**: Nivel al que se aplican las asignaciones de roles, como una suscripción, un grupo de recursos o un recurso específico.

#### Azure Policy y Zonas de Aterrizaje

**Azure Policy**: Ayuda a garantizar que los recursos en Azure se configuren y gestionen de acuerdo con tus estándares y requisitos de cumplimiento. Puedes crear, asignar y gestionar políticas para recursos de Azure.

**Zonas de Aterrizaje**: Proveen una estructura para la implementación y operación de tus cargas de trabajo en la nube, asegurando cumplimiento y mejores prácticas.

#### Fuentes de Datos de Azure Monitor

**¿Qué es Azure Monitor?**

- Azure Monitor sirve como tu centro principal para asegurar tu entorno de Azure.
- Al aprovechar su registro de actividades, obtienes una visibilidad detallada de los eventos a nivel de suscripción, lo que te permite identificar amenazas potenciales y tomar medidas rápidas.
- Este registro integral documenta actividades como modificaciones de recursos e inicios de máquinas virtuales, proporcionando un contexto valioso para comprender los cambios dentro de tu infraestructura de Azure.
- Accede a él directamente en el portal o utiliza PowerShell y el Azure CLI para su recuperación.

Azure Monitor es una plataforma para monitorear y diagnosticar problemas en aplicaciones e infraestructura.

**Fuente: Documentación de Microsoft**

#### Espacios de Trabajo de Azure Monitor Logs (Log Analytics)

- Los Espacios de Trabajo de Azure Monitor Logs (Log Analytics) son entornos únicos donde puedes recopilar y analizar datos de registro de varias fuentes.
  - Cada espacio de trabajo tiene su propio repositorio de datos y configuración.
  - Puedes combinar datos de múltiples servicios dentro de un solo espacio de trabajo.
  
Es como tener una caja de herramientas dedicada para monitorear y solucionar problemas en tus recursos en la nube y locales.
