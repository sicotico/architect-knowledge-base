# Traducción de vídeos VLC


> **Pregunta original:**
> 
VLC traduce vídeos de inglés a español ?

---


## Respuesta


Actualmente, VLC Media Player no ofrece una función integrada para traducir directamente el audio de un video del inglés al español. Sin embargo, puedes utilizar subtítulos traducidos para comprender mejor el contenido en otro idioma.

**Opciones disponibles:**

1. **Descargar subtítulos traducidos:**
   - Puedes buscar y descargar archivos de subtítulos en español (.srt) desde sitios web especializados. Una vez descargados, cárgalos en VLC mientras reproduces el video.

2. **Generar subtítulos automáticamente:**
   - VLC cuenta con complementos como VLSub que permiten buscar y descargar subtítulos directamente desde el reproductor. Este complemento busca subtítulos en línea que coincidan con tu video.

3. **Traducción manual de subtítulos:**
   - Si tienes un archivo de subtítulos en inglés, puedes traducirlo al español utilizando herramientas como Aegisub. Este proceso implica editar manualmente el texto para adaptarlo al idioma deseado. citeturn0search2
