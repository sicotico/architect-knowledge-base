### **Pregunta #1**  
Una empresa realiza pronósticos cada trimestre para decidir cómo optimizar sus operaciones y satisfacer la demanda esperada. La empresa utiliza modelos de aprendizaje automático (ML) para hacer estas previsiones.  

Un profesional de inteligencia artificial (IA) está redactando un informe sobre los modelos de ML entrenados para proporcionar transparencia y explicabilidad a los interesados de la empresa.  

**¿Qué debe incluir el profesional de IA en el informe para cumplir con los requisitos de transparencia y explicabilidad?**  

A) Código para el entrenamiento del modelo  
B) Gráficos de dependencia parcial (PDPs) **(Respuesta Correcta)**  
C) Datos de muestra utilizados para el entrenamiento  
D) Tablas de convergencia del modelo  

**Explicación:**  
Los gráficos de dependencia parcial (PDPs) son una herramienta clave para la transparencia y explicabilidad, ya que muestran cómo las características afectan las predicciones del modelo de ML. Esto ayuda a que los interesados comprendan las relaciones entre las variables de entrada y las salidas del modelo, cumpliendo con los requisitos de explicabilidad.  

**Otras opciones:**  
- **A. Código para el entrenamiento del modelo:** Proporciona detalles técnicos, pero no mejora directamente la transparencia o explicabilidad para los interesados.  
- **C. Datos de muestra para el entrenamiento:** Puede proporcionar contexto, pero no explica cómo funciona el modelo o cómo toma decisiones.  
- **D. Tablas de convergencia del modelo:** Son técnicas centradas en la optimización y no en la explicación del comportamiento del modelo.  

✅ **Respuesta seleccionada: B**
