# Atajo Safari ChatGPT Traducción


> **Pregunta original:**
> 
Tengo un iPhone 15 actualizado y necesito un atajo para compartir la URL desde safari y se abra la web de chatGPT y traduzca la web


---


## Respuesta


Crear un atajo en tu iPhone para compartir una URL desde Safari, abrir la web de ChatGPT y traducir la página requiere un enfoque basado en automatizaciones. Aquí te explico cómo configurarlo paso a paso:

---

### **Pasos para crear el Atajo**
1. **Abre la app Atajos en tu iPhone**:
   - Es la aplicación preinstalada de Apple para automatizaciones.

2. **Crea un nuevo Atajo**:
   - Pulsa el botón **"+"** para crear un nuevo atajo.
   - Asigna un nombre como "Traducir en ChatGPT".

3. **Añade las acciones necesarias**:
   - **Acción 1: Obtener la URL de entrada**
     - Pulsa en "Añadir acción".
     - Busca "Obtener entrada" y agrégala.
   - **Acción 2: Convertir la URL a un formato aceptable por ChatGPT**
     - Busca "Texto" y agrégala.
     - Escribe un formato como:
       ```
       https://chat.openai.com/chat?prompt=Translate%20the%20content%20of%20this%20URL%20into%20[LANGUAGE]%3A%20[URL]
       ```
       - Sustituye `[LANGUAGE]` por el idioma deseado (ej.: "Spanish") y `[URL]` por la entrada de la URL.
   - **Acción 3: Abrir la URL en Safari**
     - Busca "Abrir URL" y agrégala.
     - Asegúrate de conectar esta acción al texto generado previamente.

4. **Guarda el Atajo**:
   - Pulsa en "Listo" para guardar el atajo.

5. **Activa el atajo desde la hoja de compartir**:
   - Abre Safari y ve a cualquier página web.
   - Pulsa el botón de compartir (el cuadrado con una flecha hacia arriba).
   - Desliza hacia abajo y selecciona "Editar acciones".
   - Activa tu nuevo atajo "Traducir en ChatGPT".

---

### **Uso del Atajo**
1. Ve a Safari y abre la web que deseas traducir.
2. Pulsa en el botón de compartir.
3. Selecciona "Traducir en ChatGPT".
4. Se abrirá la web de ChatGPT con el texto traducido al idioma deseado.
